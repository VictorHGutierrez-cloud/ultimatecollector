## Atalhos de navegação (como falar “onde clicar”)

No produto, a navegação típica é:

1. **Sidebar** (menu à esquerda) → módulo (Time off, Performance, Organization…)
2. **Settings** (Configurações) → área (Time, Permissions, Company…)
3. **Inbox** → pedidos para aprovar
4. **Perfil do colaborador** → abas (Time off, Contract, Documents…)

Quando escrever guia para cliente, use passos numerados e o nome **oficial em inglês** do menu, com a tradução entre parênteses se ajudar.
