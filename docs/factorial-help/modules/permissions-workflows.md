## O que é

Controla **quem pode ver e fazer o quê**. Quase toda feature sensível (payroll, documents, attendance, job catalog) tem toggles dentro de um **permission group**. Workflows/automations disparam ações e notificações.

## Conceitos-chave

| Termo | Explicação |
|-------|------------|
| Permission group | Conjunto de pessoas com os mesmos acessos |
| Administrator role | Papel admin |
| Visibility | Quais pessoas/dados o grupo enxerga |
| Scope | “Para si”, “reports”, “time”, “whole company”… |
| External users | Usuários externos em grupos |
| Workflow / automation | Regra: quando X acontecer, faça Y |
| Welcome space permission group | Permissões do espaço de boas-vindas |

## Onde clicar

1. **Settings → Permissions**  
2. Escolher o grupo → ativar/desativar permissões por seção (Time, Payroll, Job catalog…)  
3. Atribuir employees ao grupo  
4. Workflows: área de Automations / Workflows (ver artigos da subcategoria)

## Dicas para guia / demo

- Nunca diga “todo mundo é admin”. Crie grupos: Employees / Managers / HR.
- Na demo, mostre a **mesma tela** com dois usuários (ou explique o que cada um vê).
- Ao falar de Time off ou Performance, cite a permissão correspondente.
