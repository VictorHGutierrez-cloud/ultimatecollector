# Projects (resumo curto)

**Help Center:** [Projects](https://help.factorialhr.com/en_US/projects) (~25 artigos)

## O que é

Gestão de **projetos**: alocar pessoas, tempo em projetos, custos, orçamento e rentabilidade. Liga-se a time tracking de projeto e, em alguns casos, ao One (project time comments).

## Para guia de cliente

- Útil se o cliente vende horas / precisa de project profitability.  
- Demo: criar projeto → alocar → lançar tempo → ver overview.
