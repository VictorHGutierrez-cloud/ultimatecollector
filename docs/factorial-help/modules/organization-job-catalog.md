# Organization, Teams & Job Catalog

**Help Center (pai):** [Recruitment & Organization](https://help.factorialhr.com/en_US/recruitment-organization)  
**Folha principal:** [Teams, jobs & organizational chart](https://help.factorialhr.com/en_US/teams-jobs-organizational-chart) (~17 artigos)

## O que é

Camada de **estrutura da empresa**: pessoas, equipes, gestores, organograma e **Job Catalog** (árvore de cargos/níveis). É a base para Performance (competências por cargo), permissões por time e demos de org design.

## Conceitos-chave

| Termo | Significado |
|-------|-------------|
| Teams / Sub-teams | Equipes e hierarquia de equipes |
| Manager | Gestor da pessoa (reporting line) |
| Organisational chart | Organograma visual |
| Job Catalog | Catálogo de roles/levels/families |
| Job attributes / working conditions | Atributos do cargo |
| Workplace / work area | Local físico / área |
| Hiring team roles | Papéis no hiring (ATS) |
| Universal Updater | Atualização em massa de registros |

## Onde clicar

1. Sidebar → **Organization** (people, teams, org chart)  
2. **Job catalog** (estrutura de cargos)  
3. Settings → Permissions → seção **Job catalog** (quem edita/vê)  
4. Perfil do employee → job / manager / team  

## Fluxo típico (sandbox / demo)

```text
Criar teams (cascade Divisão → Unidade)
  → Definir managers
  → Montar Job Catalog (families → functions → roles/levels)
  → Atribuir jobs aos employees
  → (Depois) ligar competencies aos jobs
```

## Dicas para guia de cliente

- Mostre o **org chart** e abra 1–2 perfis com manager diferente.
- Explique que competências de Performance costumam depender do **job** da pessoa.
- Competency Levels (novo) exigem o Job Catalog novo — ver artigo em Performance.
