**Help Center:** [New to Factorial? Start here!](https://help.factorialhr.com/en_US/new-to-factorial-start-here)

Conjunto de artigos para montar a conta da empresa, o perfil do colaborador e o app mobile. É o ponto de partida antes de Time off, Performance, etc.

## Conceitos-chave

- **Legal entity:** várias empresas jurídicas na mesma conta Factorial.
- **Employee importer:** planilha para criar/atualizar colaboradores em massa.
- **SSO / SAML:** login corporativo (Google, Azure, Okta).
- **API keys:** credenciais para integrações (este repositório usa muito isso).
- **Custom fields / custom tables:** campos extras no perfil ou tabelas custom.

## Onde clicar (admin)

1. Sidebar → **Settings**
2. Company / Employees / Permissions conforme o tema
3. Para API: artigos “How to Create API Keys” e contato técnico de erros de API

## Dicas para guia de cliente

- Sempre comece a demo mostrando: empresa criada → people no Organization → um perfil aberto.
- Explique a diferença **admin vs employee** cedo (evita confusão na demo).
- Se o cliente tiver várias entidades, mostre **legal entities** antes de Time off/Payroll.
