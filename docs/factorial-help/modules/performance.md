# Performance reviews

**Help Center:** [Performance review](https://help.factorialhr.com/en_US/performance-review) (~13 artigos)  
**Pai:** [Performance & Engagement](https://help.factorialhr.com/en_US/performance-engagement)

## O que é

Ciclos de **avaliação de desempenho**: questionários, participantes (avaliado, gestor, pares), autoavaliação, scores, analytics e planos de ação. Costuma conectar com **Goals** e **Competencies**.

## Conceitos-chave

| Termo | Significado |
|-------|-------------|
| Performance review / process | Ciclo ou processo de avaliação |
| Reviewee / Reviewer | Avaliado / quem avalia |
| Participants | Conjunto de papéis no review |
| Questions | Perguntas (texto livre, escalas, etc.) |
| Self-assessment | Autoavaliação |
| Peer review | Avaliação por pares |
| Weighted score | Nota ponderada (ex.: manager weight) |
| Talent analytics / Pulse | Dashboards de talento / engajamento |
| Feedbacks | Feedback contínuo fora do ciclo formal |
| Competency levels | Níveis de proficiência usados na avaliação |

## Onde clicar

1. Sidebar → **Performance**  
2. Criar/abrir um review process  
3. Configurar questions, participants, competency assessment, goals  
4. Lançar para o público-alvo  
5. Analytics após respostas  

## Fluxo típico de demo (como no STATIN)

```text
Processo Year-End (nota + bandas + accept/appeal)
  + Coaching reviews
  + Goal setting / IWP do próximo ciclo
Competências ligadas aos jobs
Metas no Goals pack
Narrativa por pessoa (bom / superior / PIP)
```

## Dicas para guia de cliente

- Separe **configuração HR** vs **experiência manager** vs **employee**.
- Mostre 1 review completo (perguntas → submit → resultado).
- Se usar competências GoJ/framework do cliente, cite o import Excel e o módulo [competencies-goals.md](competencies-goals.md).
