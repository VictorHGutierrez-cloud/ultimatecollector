# Apps, Integrations & API

**Help Center (pai):** [Apps & Integrations](https://help.factorialhr.com/en_US/apps-integrations)  
**Marketplace:** [Integrations Marketplace](https://help.factorialhr.com/en_US/integrations-marketplace)

## O que é

Como conectar a Factorial a outras ferramentas e como desenvolvedores usam a **API**. Neste repositório (Ultimate Collector) a API é o caminho principal para collect/seed/send.

## Conceitos-chave

- Feature bundles / apps instaláveis  
- Marketplace integrations (calendar, accounting, etc.)  
- API keys (criadas na conta — ver Getting started)  
- API versioning (ex.: datas tipo `2025-10-01` / `2026-07-01` na doc OpenAPI do projeto)  
- Webhooks / error notifications (contato técnico)

## Onde clicar

1. Apps / Marketplace no produto  
2. Settings / Developers → API keys  
3. Documentação externa de API: `https://apidoc.factorialhr.com/` (não é o Help Center, mas é a referência técnica)

## Dicas para guia de cliente

- Guia de negócio: fale “integração” e mostre o app no Marketplace.  
- Guia técnico: aponte OAS em `assets/oas/` deste repo + artigo “How to Create API Keys”.  
- Nunca cole tokens no guia.
