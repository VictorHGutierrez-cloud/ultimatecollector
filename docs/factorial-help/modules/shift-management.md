# Shift management — turnos

**Help Center:** [Shift management](https://help.factorialhr.com/en_US/shift-management) (~19 artigos)  
**Pai:** Time tracking & Absences

## O que é

Ferramenta para **planejar e publicar turnos** (quem trabalha quando), em vez de só uma jornada fixa. Combina com Time tracking para bater ponto sobre o turno planejado.

## Conceitos-chave

- Planning tool = Shift management (vs Fixed work schedule)
- Shift templates / publicação de turnos
- Cobertura de equipe e conflitos
- Ligação com autofill de timesheet (quando o planning tool permite)

## Onde clicar

1. Área de **Shifts / Shift management** no menu Time  
2. Settings de Time para habilitar planning tool na policy / pessoa  

## Dicas para guia

- Ideal para retail, saúde, operações 24/7.
- Na demo: monte a semana → publique → employee vê o turno → clock-in.
- Se o cliente for office 9–5, prefira **work schedules** fixos (módulo time-tracking).
