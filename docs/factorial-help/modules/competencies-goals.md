# Competencies & Goals

**Help Center:** [Competencies & goals](https://help.factorialhr.com/en_US/competencies-goals) (~6 artigos)

## O que é

- **Competencies:** skills/comportamentos padrão da empresa, agrupados, atribuídos a **jobs** e avaliados em Performance (incl. peer review).  
- **Goals:** objetivos com tracking, períodos, bulk actions e metas em cascata (parent/sub-goals).

## Conceitos-chave

| Termo | Significado |
|-------|-------------|
| Competency | Competência |
| Competency group | Grupo (Soft skills, Leadership, Technical…) |
| Assignment to jobs / company | Quem será avaliado naquela competência |
| Competency levels | Escala de proficiência (Basic → Advanced…) |
| Goals | Metas |
| Targets by periods | Marcos ao longo da vida da meta |
| Cascading goals | Meta pai → sub-metas |
| Bulk delete / import | Ações em massa |

## Onde clicar

1. **Performance → Competencies** (criar, grupos, levels, jobs)  
2. **Goals** (criar, cascata, import/bulk)  
3. No review: habilitar competency assessment  

## Ligação com este repositório

Clientes como STATIN / SZV usam Excel de import:

- `competenciesimport.xlsx`
- `competencies_competency_assignment_importer.xlsx`

O Help Center explica o conceito no produto; os arquivos do cliente trazem o framework específico (ex. GoJ).

## Dicas para guia

- Mostre: competency → ligada ao job → aparece só para quem tem aquele job no review.  
- Goals: mostre uma meta de unidade cascateando para indivíduo.  
- Não prometa Competency Levels sem Job Catalog novo (ver artigo “Competency levels in Performance reviews”).
