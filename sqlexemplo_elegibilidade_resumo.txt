  1. (V1) Jamaica Vacation Accrual — Monthly Close Summary   ← THIS FILE (month-end)

  4. (V1) Jamaica Vacation Accrual — Absence Proof (A/B/C)   ← sqlexemplo_power.txt (demo/proof)

PURPOSE:
  Jamaica daily rule: vacation accrues ONLY on days the employee is active
  (= not on a blocking leave). ANY blocking leave day → no vacation accrual
  that day — even if the absence is shorter than 14 calendar days.

  This report answers (in ONE run):
    • C_Gap_This_Period     = how much to subtract for Data_init..Data_end
      (normally = the month you are closing)
    • C_Gap_YTD             = how much SHOULD have been subtracted from
      1 Jan of that year through Data_end (catch-up / control)
    • What_Client_Should_Do = plain HR action for this close

  The >14 flag is EXTRA process info. It does NOT gate the gap.

CLIENT PROCESS (recommended — 1 vacation counter, not two):
  1. Keep ONE vacation allowance accruing as Factorial does (do not pause it).
  2. Each month-end: set Data_init=first day of month, Data_end=last day.
  3. For each employee with C_Gap_This_Period > 0 → subtract that amount
     (Time Off → manual adjustment). Note the amount in a simple log
     (Excel: employee | month | amount | date done).
  4. If you forgot a past month: look at C_Gap_YTD. Subtract
     (YTD − sum of adjustments already logged this year). That catches up.
  5. Do NOT create a second identical counter for “depara” in production —
     this report IS the depara. Two counters confuse who books leave.

Filters: {{Data_init}} / {{Data_end}}
  • Month close example: 2026-06-01 .. 2026-06-30
      → C_Gap_This_Period = June only; C_Gap_YTD = Jan 1 .. Jun 30
Demo tips:
  • Ex.1 Bernarda Baker (sick Jun 1–7)
      Data_init=2026-06-01  Data_end=2026-06-30
      Expect period Gap≈0.3836

per_employee AS (
    SELECT
        eb.employee_id,
        eb.employee_code,
        eb.employee_name,
        eb.tenure_start_date,
        eb.annual_vacation_days,
        eb.max_accumulation_days,
        eb.days_in_year,
        eb.days_in_period,
        eb.days_in_ytd,
        eb.period_start,
        eb.period_end,
        eb.year_start,
        eb.pause_threshold_days,
        eb.accrual_per_calendar_day,
        COALESCE(SUM(CASE WHEN s.days_off_in_period > 0 THEN s.days_off_in_period ELSE 0 END), 0)
            AS days_off_raw_sum,
        COALESCE(SUM(CASE WHEN s.days_off_in_ytd > 0 THEN s.days_off_in_ytd ELSE 0 END), 0)
            AS days_off_ytd_raw_sum,
        COALESCE(SUM(CASE WHEN s.days_off_in_period > 0 THEN 1 ELSE 0 END), 0)
            AS blocking_absences_count,
        COALESCE(MAX(s.is_extended_pause_absence), 0) AS has_extended_pause_flag
    FROM employee_base eb
    LEFT JOIN blocking_leave_slices s ON s.employee_id = eb.employee_id
    GROUP BY
        eb.employee_id,
        eb.employee_code,
        eb.employee_name,
        eb.tenure_start_date,
        eb.annual_vacation_days,
        eb.max_accumulation_days,
        eb.days_in_year,
        eb.days_in_period,
        eb.days_in_ytd,
        eb.period_start,
        eb.period_end,
        eb.year_start,
        eb.pause_threshold_days,

calc AS (
    SELECT
        pe.*,
        CASE
            WHEN pe.days_off_raw_sum > pe.days_in_period THEN pe.days_in_period
            ELSE pe.days_off_raw_sum
        END AS days_on_blocking_leave,
        pe.days_in_period - CASE
            WHEN pe.days_off_raw_sum > pe.days_in_period THEN pe.days_in_period
            ELSE pe.days_off_raw_sum
        END AS eligible_days,
        CASE
            WHEN pe.days_off_ytd_raw_sum > pe.days_in_ytd THEN pe.days_in_ytd
            ELSE pe.days_off_ytd_raw_sum
        END AS days_on_blocking_leave_ytd,
        pe.days_in_ytd - CASE
            WHEN pe.days_off_ytd_raw_sum > pe.days_in_ytd THEN pe.days_in_ytd
            ELSE pe.days_off_ytd_raw_sum
        END AS eligible_days_ytd,
        ROUND(pe.days_in_period * pe.accrual_per_calendar_day, 4)
            AS factorial_accrual_if_full_period,
        ROUND(
            (pe.days_in_period - CASE
                WHEN pe.days_off_raw_sum > pe.days_in_period THEN pe.days_in_period
                ELSE pe.days_off_raw_sum
            END) * pe.accrual_per_calendar_day
        , 4) AS jamaica_accrual_period,
        ROUND(
            (CASE
                WHEN pe.days_off_raw_sum > pe.days_in_period THEN pe.days_in_period
                ELSE pe.days_off_raw_sum
            END) * pe.accrual_per_calendar_day
        , 4) AS gap_this_period,
        FLOOR(
            ROUND(
                (CASE
                    WHEN pe.days_off_raw_sum > pe.days_in_period THEN pe.days_in_period
                    ELSE pe.days_off_raw_sum
                END) * pe.accrual_per_calendar_day
            , 6) + 0.5
        ) AS gap_this_period_rounded,
        ROUND(
            (CASE
                WHEN pe.days_off_ytd_raw_sum > pe.days_in_ytd THEN pe.days_in_ytd
                ELSE pe.days_off_ytd_raw_sum
            END) * pe.accrual_per_calendar_day
        , 4) AS gap_ytd,
        FLOOR(
            ROUND(
                (CASE
                    WHEN pe.days_off_ytd_raw_sum > pe.days_in_ytd THEN pe.days_in_ytd
                    ELSE pe.days_off_ytd_raw_sum
                END) * pe.accrual_per_calendar_day
            , 6) + 0.5
        ) AS gap_ytd_rounded
    FROM per_employee pe
)

SELECT
    employee_code                         AS "Employee_Code",
    employee_name                         AS "Employee_Name",
    tenure_start_date                     AS "Tenure_Start_Date",
    annual_vacation_days                  AS "Annual_Entitlement_Days",
    max_accumulation_days                 AS "Max_Accumulation_3y",
    days_in_year                          AS "Days_In_Year_365_or_366",
    year_start                            AS "Year_Start",
    period_start                          AS "Period_Start",
    period_end                            AS "Period_End",
    days_in_period                        AS "Days_In_Period",
    days_in_ytd                           AS "Days_In_YTD",
    ROUND(accrual_per_calendar_day, 6)    AS "Accrual_Per_Calendar_Day",

    days_on_blocking_leave                AS "Days_Off_This_Period",
    eligible_days                         AS "Eligible_Days_This_Period",
    blocking_absences_count               AS "Blocking_Absences_This_Period",
    factorial_accrual_if_full_period      AS "A_Factorial_Accrual_If_Full_Period",
    jamaica_accrual_period                AS "B_Jamaica_Accrual_This_Period",
    gap_this_period                       AS "C_Gap_This_Period",
    gap_this_period_rounded               AS "C_Gap_This_Period_Rounded",

    days_on_blocking_leave_ytd            AS "Days_Off_YTD",
    eligible_days_ytd                     AS "Eligible_Days_YTD",
    gap_ytd                               AS "C_Gap_YTD_Should_Have_Subtracted",
    gap_ytd_rounded                       AS "C_Gap_YTD_Rounded",

    CASE
        WHEN has_extended_pause_flag = 1
        THEN 'YES (>14 calendar-day absence touching YTD window)'
        ELSE 'NO'
    END                                   AS "Has_Extended_Pause_Flag",

    CASE
        WHEN COALESCE(gap_this_period, 0) > 0 THEN
            CONCAT(
                'THIS MONTH: Factorial accrued ~',
                CAST(gap_this_period AS varchar),
                ' vacation day(s) too much in Period_Start..Period_End. ',
                'Manually SUBTRACT ',
                CAST(gap_this_period AS varchar),
                ' day(s) from vacation balance (Time Off -> adjustment). ',
                'YTD CONTROL: from Year_Start through Period_End, total that should ',
                'have been subtracted so far ~ ',
                CAST(gap_ytd AS varchar),
                ' day(s). If you forgot earlier months, catch-up = YTD minus what you ',
                'already adjusted this year (use your Excel log). ',
                'Do this whether leave was above or below 14 days.'
            )
        WHEN COALESCE(gap_ytd, 0) > 0 THEN
            CONCAT(
                'THIS MONTH: no new gap in Period_Start..Period_End. ',
                'YTD CONTROL: total that should have been subtracted Jan..Period_End ~ ',
                CAST(gap_ytd AS varchar),
                ' day(s). If your Excel log shows less than that already adjusted, ',
                'catch up the difference now.'
            )
        ELSE
            'No action. No blocking-leave gap this period or YTD for this employee.'
    END                                   AS "What_Client_Should_Do",

    CASE
        WHEN days_on_blocking_leave = 0 AND days_on_blocking_leave_ytd = 0 THEN
            'No blocking leave in period or YTD. Jamaica accrual = full calendar.'
        ELSE
            CONCAT(
                'Period off ', CAST(days_on_blocking_leave AS varchar),
                'd -> gap ', CAST(gap_this_period AS varchar),
                '. YTD off ', CAST(days_on_blocking_leave_ytd AS varchar),
                'd -> gap ', CAST(gap_ytd AS varchar), '.'
            )
    END                                   AS "Conclusion_Eligibility"
FROM calc
WHERE annual_vacation_days IS NOT NULL
ORDER BY
    CASE WHEN gap_this_period > 0 THEN 0 ELSE 1 END,
    gap_this_period DESC,
    gap_ytd DESC,
    employee_name
;
